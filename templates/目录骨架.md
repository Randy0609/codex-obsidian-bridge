# 目录骨架 · 一套可直接抄的 vault 结构

> 用法:在你的 Obsidian vault 里照着建目录,把每个目录下的「使用说明」复制存成该目录里的 `使用说明.md`。四个核心目录跑顺了,再按需扩展。

## 最小可用版(先跑通这四个)

```
我的公司知识库/
├── AGENTS.md            ← AI 员工上岗手册(见 templates/AGENTS.md)
├── 00_收件箱/
│   └── 使用说明.md
├── 01_任务包/
│   └── 使用说明.md
├── 02_交付物/
│   └── 使用说明.md
└── 03_会话记忆/
    └── 使用说明.md
```

## 各目录使用说明(复制即用)

### 00_收件箱/使用说明.md

```markdown
# 收件箱使用说明

这里扔原料,不做任何整理:
- 会议/通话录音的转写文字
- 微信重要聊天记录(全选复制即可)
- 灵感、想法、随手记
- 值得留存的网页摘录、客户反馈

规矩:
1. 只管扔,别整理——整理是 AI 的活
2. 文件名随手起,带日期最好:0920-老李电话.md
3. 每周对 AI 说一次:"整理收件箱,给出归档建议"
```

### 01_任务包/使用说明.md

```markdown
# 任务包使用说明

这里写任务书,一个任务一个文件,命名 MMDD-任务名.md。

任务书三段式:
## 需求 —— 做什么、给谁看、解决什么问题
## 交付 —— 成品放哪、叫什么、什么格式
## 验收标准 —— 可检查的硬标准(数字有出处、格式照某样例)

心法:当新来的聪明员工带——背景说清,标准给足,别管过程。
```

### 02_交付物/使用说明.md

```markdown
# 交付物使用说明

AI 的所有成品只放这里,命名 MMDD-交付物名.md,与任务书对应。

规矩:
1. 我只验收这个文件夹,成品不许散落别处
2. 不合格 → 退回,在原任务书里补要求重做
3. 好的成品可以当"样例",以后任务书里直接引用它的格式
```

### 03_会话记忆/使用说明.md

```markdown
# 会话记忆使用说明

AI 每次干完活在这里写纪要:MMDD-纪要.md,10 行以内:
- 做了什么
- 发现了什么
- 下次要注意什么

每周让 AI 回顾全部纪要,把教训沉淀成规则,报批后写进 AGENTS.md。
这是 AI 越用越懂你的关键。
```

## 实战版:一个跑了一年、9,500+ 篇的知识库长这样(脱敏)

四个目录跑顺之后,参照下面这张经过真实业务验证的地图演进(完整拆解见 [真实案例](../docs/05-真实案例-脱敏的知识库全景.md)):

```
我的公司知识库/
├── AGENTS.md            ← AI 员工总手册(宪法)
├── 00_收件箱/           ← 原料传送带:只扔不整,每周 AI 清一次
├── 00_工作台/           ← 每天一篇 MMDD.md:派活、决策、草稿(和 AI 的每日同步协议)
├── 00_系统入口/         ← 总索引 MOC:开工第一眼,导航到一切
├── 01_项目库/           ← 一事一夹:每个项目从立项到结案
├── 02_技能库/           ← SOP、话术、检查清单等可复用方法
├── 10_业务与项目/       ← 业务线顶层文档(只放"正在用的刀",几十篇以内)
├── 20_内容与IP/         ← 选题、内容日历、个人品牌
├── 30_研究与知识/       ← 资产区:行业研究、AI 摄入的情报,可以长到几千篇
├── 40_Agent与自动化/    ← AI 团队工位:每个 AI 席位一个文件夹(身份卡/任务包/产出)
├── 50_个人与关系/       ← 人脉与合作方
├── 70_客户与合作/       ← 客户档案(敏感 → 在 AGENTS.md 设为禁区)
└── 90_归档与旧目录/     ← 只进不出
```

**健康标志**:入口小(收件箱几十篇)、操作区瘦(工作台/业务几百篇)、资产区厚(研究几千篇)。胖在资产、瘦在操作,才用得动。

## 演进路线(不要一步到位)

1. **第 1 周**:四个核心目录 + AGENTS.md,先把 AI 用起来
2. **第 1 个月**:加工作台(每日笔记)+ 系统入口(索引),日常系统成型
3. **第 2~3 个月**:长出项目库和研究区,让 AI 批量摄入资料
4. **半年后**:自然长出自己的"40_Agent与自动化"——你不再是用 AI,是在带 AI 团队

> 原则:**从四个目录开始,用出痛了再加**。目录不是越多越好,是 AI 和你都能记住才好。
