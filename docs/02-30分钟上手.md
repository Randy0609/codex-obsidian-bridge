# 02 · 30 分钟上手:从零跑通第一个任务

目标:30 分钟后,你的 AI 员工在**你自己的知识库**里完成第一份交付物。全程不需要写代码。

## 第 1 步 · 装 Obsidian(5 分钟)

1. 打开 [obsidian.md](https://obsidian.md),下载安装(免费,全平台)
2. 首次启动 → **Create new vault** → 起个名字(比如 `我的公司知识库`)→ 选一个你记得住的本地文件夹位置
3. 进去后是一片空白——正常,下一步建骨架

> 卡点:Mac 用户注意,选"我自己的"文件夹位置(如 `文档` 目录),别放 iCloud 同步目录,避免和 AI 读写打架。

## 第 2 步 · 建目录骨架(5 分钟)

按 [templates/目录骨架.md](../templates/目录骨架.md) 把四个核心目录建出来。最快的方式:直接让 Obsidian 新建四个文件夹:

```
00_收件箱/
01_任务包/
02_交付物/
03_会话记忆/
```

再把 `目录骨架.md` 里每个目录的"使用说明"各存成一个 `使用说明.md` 放进去(模板里都写好了,复制即可)。

## 第 3 步 · 装 Codex(5 分钟)

两条路任选:

- **VS Code 路(推荐新手)**:安装 [VS Code](https://code.visualstudio.com) → 扩展市场搜 **Codex** → 安装 → 登录你的 ChatGPT 账号
- **终端路(熟练后)**:`npm i -g @openai/codex`,终端里 `codex` 启动

## 第 4 步 · 放上岗手册,让 AI 认门(10 分钟)

1. 把 [templates/AGENTS.md](../templates/AGENTS.md) 的内容复制,在 vault 根目录存为 `AGENTS.md`
2. 按文件里的 `<!-- 注释 -->` 提示,改成你的实际情况:
   - 你的行业和业务一句话
   - 你的交付标准(比如"给我看的数字必须有出处")
   - 你的禁区(比如"客户名单目录不许改")
3. 用 Codex **打开整个 vault 文件夹**(不是单个文件),它就会自动读到这份手册

> 原理:Codex 启动时会自动读取工作目录里的 AGENTS.md,这相当于给 AI 员工的入职培训。

## 第 5 步 · 派第一个任务(5 分钟)

1. 在 `00_收件箱/` 扔一份原料:随便一段你最近的业务记录、会议录音转写、或客户反馈
2. 在 `01_任务包/` 新建 `250920-第一次任务.md`,写三行:

```markdown
## 需求
把收件箱里这份记录,整理成一页《客户反馈摘要》:问题按严重程度排序,每条附原文出处。

## 交付
成品存到 02_交付物/,文件名:250920-客户反馈摘要.md

## 验收标准
- 每条反馈都标了原文位置
- 没有编造记录里不存在的内容
```

3. 对 Codex 说:**"读取 01_任务包/250920-第一次任务.md,按需求执行"**
4. 它读完收件箱、产出成品、放进交付区。你打开 `02_交付物/` 验收

## 跑通之后

- 把 [docs/03-日常工作流.md](03-日常工作流.md) 的循环用起来,这是每天的主节奏
- 用一周后,回头把 AGENTS.md 补充你发现的规矩——手册是越用越厚的
- 遇到问题 → [常见问题](04-常见问题.md)
