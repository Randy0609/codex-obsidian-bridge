# Codex Obsidian Bridge · 用 Codex + Obsidian 给中小企业搭一个「本地优先」AI 工作台

> 给中小企业经营者、老板的开源起点:把 **Obsidian** 当你的第二大脑,把 **Codex** 当你的 AI 员工,用一套简单约定把两者打通——AI 直接在你的知识库里干活,数据始终在你自己电脑上。

## 这解决什么问题

大多数老板用 AI 的现状:**聊天框式用 AI**——复制一段资料、问一个问题、得到一段回答、再手动搬回自己的文档。资料散落在微信、网盘、笔记本里,AI 每次都"失忆",从头了解你的业务。

这个仓库提供另一条路:

```
你的知识库(Obsidian,本地 Markdown 文件)
        ↕  一套目录约定 + 一份 AGENTS.md 上岗手册
你的 AI 员工(Codex,能读写文件、执行任务、交付结果)
```

打通之后,变化是:

- **AI 不再失忆**:客户资料、经营数据、内容素材都在知识库里,AI 随取随用
- **从"问答"到"交付"**:你说需求,AI 直接产出成品文档放进你的交付区,而不是聊天框里一段话
- **数据在自己手里**:全部是本地文件,不上传任何服务器,客户名单、经营数据不出你的电脑
- **结果可检查**:AI 每次干完活留下交付物和记录,做得好不好,一眼能查

## 这套东西的来源

这不是理论框架,是一套**已经在真实电商业务里每天在用**的工作方式:知识库驱动经营日报、会员运营、内容生产,多个不同分工的 Codex 席位在同一个知识库里协作。本仓库只讲**通用的方法和模板**,不包含任何业务数据。

## 快速开始(30 分钟)

1. **装 Obsidian**(免费):[obsidian.md](https://obsidian.md),新建一个空仓库(vault)
2. **抄目录骨架**:把 [templates/目录骨架.md](templates/目录骨架.md) 里的结构建出来
3. **装 Codex**:VS Code 装 Codex 扩展,或终端装 Codex CLI,用 Codex 打开你的 vault 文件夹
4. **放上岗手册**:把 [templates/AGENTS.md](templates/AGENTS.md) 复制到 vault 根目录,按注释改成你的业务
5. **派第一个任务**:见 [docs/02-30分钟上手.md](docs/02-30分钟上手.md) 的实战示例

详细每一步(含截图位和常见卡点)→ [30 分钟上手指南](docs/02-30分钟上手.md)

## 用起来是什么样(日常工作流)

```
00_收件箱/          ← 随手扔:语音转写、聊天记录、灵感、截图
01_任务包/          ← 你派活:每个任务一个文件夹(需求.md)
02_交付物/          ← AI 交活:成品文档,你验收
03_会话记忆/        ← AI 记事:每次干活的纪要,越用越懂你
```

一句话:**你往收件箱扔原料、在任务包写需求,AI 在交付物交成品、在会话记忆记笔记。** → [日常工作流详解](docs/03-日常工作流.md)

## 适合谁

- 中小企业经营者/老板:想用 AI 但不想把公司数据交给云端
- 一个人当一支队伍用的超级个体:电商、咨询、自媒体、专业服务
- 团队的"AI 推广负责人":想给老板/同事一套不依赖技术的落地方法

**不需要会写代码。** 全程只用三样东西:Obsidian(免费)、Codex(订阅制)、一套文件夹约定。
